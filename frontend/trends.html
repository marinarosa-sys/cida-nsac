🔍 Transparent Model Rules — How This Simulation Evaluates Your Rotation EMBRAPA Rotation Matrix + FAO EcoCrop + NASA POWER/SMAP
1. Soil Nutrient Carryover Legumes (Soybean, Bean) fix atmospheric Nitrogen (+35 to +55 kg N/ha residual) for the next grass crop. Grasses (Corn, Sorghum) recycle deep Potassium (K) and leave moisture-retaining straw mulch.
2. Monoculture & Pest Check Repeating the same botanical family consecutively without a break crop reduces N availability (-8%) and increases root pathogen / nematode pressure.
3. Climate & Cycle Window Each crop's start month and cycle duration (days) are checked against regional rainfall/thermal windows (NASA POWER/SMAP) and FAO minimum phenological cycles.
4. Your Real Harvest Baseline Base yield (t/ha) is calibrated directly from your completed harvests in My Crops (or regional FAO baseline if no prior harvest exists yet).
